# Minimal

**Read what matters.**

Minimal is a clean, distraction-free reading app designed to help you discover and enjoy stories based on the topics you care about.

No clutter. No overwhelming feeds. Just a simple reading experience focused on the content.

## Features

* Personalized topics
* Clean reading experience
* Light and dark mode
* Offline reading
* Save articles for later
* Reading history
* Progressive Web App support
* Responsive experience across devices

## Vision

Minimal is built around one idea:

> **Less noise. More reading.**
